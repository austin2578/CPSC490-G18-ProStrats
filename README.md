## Project summary

Project Rogue is a 2D action roguelite platformer focused on player-driven buildcraft and replayability. Runs progress through three semi-random branching acts containing handcrafted combat, traversal, puzzle, event, shop, elite, and other encounter rooms. Classes establish the player's starting attributes, equipment, passive choices, and identity without restricting later weapon choices, while weapons evolve through attribute scaling, randomized affixes, branching skill trees, and synergistic boons. By the end of the semester, the team plans to have a documented and playable Unity prototype demonstrating the project's core gameplay systems and technical architecture.
